# Raspberry Pi 5 Basic Tutorials

Welcome to the **Raspberry Pi 5 Basic Tutorials** series.

This tutorial series is designed for beginners who are getting started with the Raspberry Pi 5. The lessons cover the initial hardware introduction, Raspberry Pi OS installation, remote access using SSH and VNC, Wi-Fi configuration, and commonly used Linux terminal commands.

## Contents

### [Lesson 1: Introduction to Raspberry Pi 5](01_Introduction.md)

Learn about the Raspberry Pi 5, its major hardware components, connectors, GPIO header, and common applications.

### [Lesson 2: Clean Formatting an SD Card Previously Used in a Raspberry Pi](02_Clean-Formatting-An-Used-RPi-SD-Card.md)

Learn how to clean and prepare a previously used Raspberry Pi microSD card before installing a fresh operating system.

### [Lesson 3: Installing Raspberry Pi OS and Connecting via SSH](03_Installing-Raspberry-Pi-OS-and-Connecting-via-SSH.md)

Install Raspberry Pi OS using Raspberry Pi Imager, configure the initial system settings, enable SSH, find the Raspberry Pi's IP address, and connect to it remotely from your computer.

### [Lesson 4: Configuring Remote Desktop Access with VNC](04_Configuring_Remote_Desktop_Access_with_VNC.md)

Configure VNC on the Raspberry Pi and remotely access the Raspberry Pi OS graphical desktop from your computer.

### [Lesson 5: Changing the Wi-Fi Network of Your Raspberry Pi](05_Changing_the_Wi-Fi_Network_of_Your_Raspberry_Pi.md)

Learn how to connect your Raspberry Pi to different Wi-Fi networks, including home/personal Wi-Fi and WPA2-Enterprise networks, using the Raspberry Pi desktop and terminal.

### [Lesson 6: Frequently Used Raspberry Pi Terminal Commands](06_Frequently_Used_Raspberry_Pi_Terminal_Commands.md)

A beginner-friendly reference to commonly used Linux and Raspberry Pi terminal commands for navigation, file management, networking, software installation, system monitoring, process management, and more.

---

## Recommended Learning Order

If you are setting up a Raspberry Pi for the first time, follow the lessons in order:

**Lesson 1 → Lesson 2 (if required) → Lesson 3 → Lesson 4 → Lesson 5 → Lesson 6**

> 💡 **Note:** Lesson 2 can be skipped if you are using a brand-new microSD card.
